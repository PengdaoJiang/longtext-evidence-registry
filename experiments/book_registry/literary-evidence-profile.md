# 文学证据登记规范 literary-evidence-v3

用途：为后续模型重建人物、事件、场景、概念及文学联系保存可回查的证据。不是要求抽取模型评价主题或文学价值。本规范补充 worker.md；使用现有 book-registry-v1 Schema，不改变原文和表结构。batch_id 使用 `literary-evidence-v3/工作者/任务/批次` 前缀，保存本次实际使用的提示文件。v3 于 2026-09-27 收紧独立条目的准入粒度。

用户已明确采用全书回顾视角：阅读范围可以大于领取范围，后文章节可用来确认前文身份、指代及联系。不设置无剧透或预测式的信息截止点。仍只登记领取范围内的内容；外章作为辅助证据注明段落与引文，不顺手抽取外章无关事实。关系的阶段变化、角色说法和现实发生与是否提前获知无关，仍须区分。

“服务领取范围”允许用辅助章节补全正文已经出现的实体，包括姓名、别名和亲属身份；不能误解成只要名字未在正文逐字出现就禁止回填。复用原 ID 和登记名，在该实体下用 `attribute name/alias/nickname`（每条一个称形）保存有根据的命名，正文证据锚定所指实体，`context_support` 保存名称依据。名称事实的极性、情态和来源照实填写。名称检索以未否决的正向实际命名事实为派生索引，保留出处；不静默覆盖原标签，也不把计划改名、否认某名字等记录当作现用姓名。

## 先判断是否需要进入知识层

逐段核读不等于逐句、逐动作、逐次发言建立条目。默认让普通寒暄、点头、注视、询问、走动和重复铺陈留在原文；只有原文支持独立信息用途时才提升。不能把这些词当黑名单，同样的动作也可能有实质后果。

提升前回答：省去这个独立条目后，既有记录将缺失哪一项身份／关系信息、事态变化、决策依据、信息差或可追踪的联系？具体判据：

- 新的身份、概念规则，或身份／关系／持有／能力／处境等发生了需要保留阶段的变化。瞬间的姿势或表情变化本身不自动达标。
- 引语提供新的可区分命题、误解、隐瞒、承诺、命令、威胁或决定，且这些内容服务人物关系、行动条件或后续后果。普通交谈不自动推导 knows，也不把“说了话”本身当信息增益。
- 有原文支持的因果、目标、履行／违背，或者其他段落明确回指、比较、解释此事。仅有 before／after、共享场景或重复出现不能充当这种联系。
- 具体可观察的反应差异值得与同一过程关联，例如问话未被听见、常规反应缺失、同一对象先后不同的评价。保留观察与联系，不先命名主题或象征。

优先在既有实体下增加有来源的属性／关系。确需多个角色、结果、条件或跨段回指时，以最小完整过程建一个事件；问—答—反应、交付—接收等连续过程通常无需逐句拆成互相 before 的微节点。可用完整本章／邻章看清过程边界，context_support 服务正文事件，不能以批次截止切碎语义过程。

一次独立言语／命题节点若仅重复 speaker、addressee、content、in_scene 和普通先后，先检查其内容是否已有更直接的事实表示。普通问候／询问保留原文即可；实质命题优先落为带 speaker、attribution、modality 的事实。只有话语本身被相信、否认、引用、履行，或有其他需要独立追踪的用途，才保留话语节点。不能为了通过检查而编造后果或多加一条空泛 associated_with。

对独立用途拿不准时，在 unresolved 留具体段落和原因，交源文复核；不要以“可能有文学价值”作为万能准入理由。已有记录是否真实、是否值得独立进入入口层是两个判断；不能因粒度过细就把真实内容判假。原文锚点和历史记录仍然保留。

## 每个正文段落检查什么

逐段检查下列适用内容；没有出现的维度不用硬造记录。不因一段没有新名字就跳过。不得沿用并发探针中的“最多 14 条事实”限制；完整抽取按自然场景、约 5–10 段分批，复杂段可以单独一批。

| 维度 | 应保存的可观察内容 | 不得自行升级的解释 |
| --- | --- | --- |
| 对象与指代 | 人、物、地、势力、术法／制度／概念；姓名、别名、代词、称谓及身份范围 | 同名就是同人；同一种器物就是同一件 |
| 事件与场景 | 谁对谁做了什么、对象、地点、场景、结果；发言／选择／拒绝／未行动也可能是事件 | 共现就是关系；先发生就是原因 |
| 状态变化 | 当时持有／归属／成员／位置／能力／伤势，获得、失去、转移、加入、退出 | 当前关系永久成立；后来的状态覆盖早先状态 |
| 说话与认知 | 谁说、对谁说、原话或忠实命题；谁知道、相信、误认为、隐瞒、希望什么，正文明确的依据 | 人物声称 P 就把 P 当作世界事实；仅从表情猜心理 |
| 时间与联系 | 原文次序；故事 before/after；明确因果、条件、目标、承诺及履行／违反；回忆、梦境、假设框架 | 把预言、计划当成已发生；跨框架机械排序 |
| 叙述与措辞 | 明确视角、动作细节、感官描写、称呼变化、反复出现的词句／物象，保留引文和位置 | 直接命名“伏笔”“象征”“讽刺”“主题”并作为事实 |

原文完整保留。重复次数、措辞差异和位置可以从原文索引取得；有具体对照或回指用途的重复现象才进入这一层，不为每次重复再复制一个独立事件。是否提升按上面的信息用途核查，不承诺用一张图代替文体、节奏或阅读体验。

## 用现有结构表达

1. 独立事件使用 `kind=event`，场景使用 `scene`。先登记参与者，再用事件角色联系。事件有原文支持时连接主体、受事、物品、地点及场景；不能只建一个事件名称却不接角色。
2. 需要表达“某人的判断内容”时，使用 `kind=proposition` 条目，`attribute/content` 保存简要命题及逐字证据，再记录人物 `believes`／`claims`／`knows` 指向命题。`knows` 只用于原文明示知道的情况；“以为”用 believes。否认、否定命题与否定说话行为分清。
3. 达到准入条件且确需独立引用的言语可建 `kind=utterance`，连接 `speaker`、`addressee`、`content`。角色槽齐全只是表示完整，不是建立独立条目的理由。为人物的话登记事实时填 `attribution=character` 与 speaker；不知道说话者时保留未决项，不能借最近的姓名硬配。
4. 关系变化可建 `kind=state`，连接状态主体与内容，事件通过 `before_state`／`after_state` 指向状态。普通关系也须用 story_time、frame、note 保留适用阶段、条件与结束线索，避免“曾经拥有”变成永久拥有。
5. 可观察的语言细节使用 `kind=text_feature`，保存 `attribute/content` 的原话；需要时以 `in_scene`、`describes` 联系场景和对象。只登记正文中的具体措辞、感觉、动作、并列或重复现象；跨章的象征／伏笔判断留给后续带证据的解释层。
6. 场景／事件用 before 等 temporal 事实建立有证据的时间约束；这些关系用 object 连接另一个事件等。原文写明“清晨”等时间时，可用 temporal occurs_at 加 value 保存描述，无需另造时间节点或绝对日期。原文位置由程序算；故事时间未知就保持未知。不把整个故事强排成没有并列、回忆与不确定性的唯一年表。

## 优先使用的关系名与方向

这是一组约定，不封死扩展。无法忠实表达时保留新标签和精确 note，不套近似关系。

- 事件 → 对象：主动行为者用 `agent`；受到动作影响的对象用 `patient`；心理感受者用 `experiencer`，引发感受的对象用 `stimulus`；观察、计数等指向的对象用 `observed_target`；非自主运动或变化的主体用 `theme`；中性参与者用 `participant`。不要把所有语法主语叫 agent、所有宾语叫 patient。
- `recipient` 表示接收者，`item` 表示实体物品，`utterance`／`content` 可指向言语／命题。`location` 指向地理地点，`in_scene` 指向叙事场景；场景不等于其空间位置。`before_state`／`after_state` 指向状态。
- 物品 → 人／组织：`owned_by`（所有权）、`held_by`（当前持有）、`held_in_custody_by`（代为保管）。三者不互换。
- 人物 → 组织／位置：`member_of`、`located_at`，保留生效阶段。
- 人物 → 命题／目标：`claims`、`believes`、`knows`、`desires`、`conceals`。这些联系自身的真假与命题内容真假分开。
- 言语 → 对象：`speaker`、`addressee`；命题／言语 → 文字用 attribute `content`。
- 事件 → 事件：`causes`、`enables`、`prevents`、`fulfills`、`violates` 只在正文给出依据时登记；单纯先后使用 temporal `before`／`after`。
- 同指用 identity `same_as`／`different_from`，不靠名称覆盖和删除来合并。

对于需要推断的联系，使用 `attribution=inference`、明确 note，并保留 unresolved 或后续复核；它不会因为写入就成为既定事实。世界事实、角色说法和解释候选不能在入口视图中混成一种确定关系。

## 表示的约束与节制

- story_time 只记录故事中的时间表述或相对阶段；没有就填 null。SU/P 段落 ID 属于证据位置，不能填进 story_time。文本先后不自动构成故事先后。
- 名词短语带范围：部分成员的年龄、动作或观点不能提升为整个群体的共同属性；新到者、全部参加者、其中三人可以是不同群体。若范围不可确定，保留原文量词和未决。
- 类别、个体与集合分清：泛指“书籍”不能直接充当某人手中那一本书；“弟子”这一身份类别不等于某个到场弟子群。同名候选须复核本段指称的粒度和语境，不为减少重复而强行复用。宁可暂存独立候选，再用有证据的 identity 关系关联。
- 证据须支持完整事实及指代主体。只引“内心”“他”“每次”不足以独立解析时，扩大到同句或补上相关段的引文；不能让下游靠隐藏上下文猜主体。
- 紧凑格式中，事实与条目可用 quote=null 的整段锚点，由程序附上原段全文；正文段落通常很短，不必为了细摘引文而漏掉同段施事或动作。mentions 仍用最小准确称形／代词的逐字引文，保留提及级字符位置；人物提及与事实证据粒度分开。
- 正常的跨句、跨段指代可结合完整章节解析，不要求每句都重复姓名。多个片段联合确定了主体，就记录联系与辅助出处；仍存在多个同样合理的解释时才保留未决，不因省略主语而机械放弃。
- 条目的可读名称不代替关系：叫“某人之父”“某家的店铺”并没有建立父子或归属边。逐段反查原文明示的亲属、部分与整体、人物所属家庭、命名／别名关系是否有可检索的记录；不可为了名字丰富而漏掉这些基础连接。
- 命题和原话也不代替关系端点。已有条目之间的实质关系须显式连接，例如“甲说乙属于丙”应保留乙→丙的 member_of，并填写 character、speaker=甲；不能只留下甲→命题→一段含乙丙名字的文字。命题中确有多个参与者时连接对应角色。检查已登记的人、物、组织、概念有没有只出现在 content 字符串中而没有关系；不把单纯共现变成关系。
- 极性针对本条所断言的关系。保存“某人的原话/命题内容是『不去』”时，content 的极性仍为 positive；不要因内容含否定词就再次设 negative，形成双重否定。单独登记“某人去某地”被否定时才将该行为关系设为 negative。
- planned、hypothetical、conditional 的事件不能直接接入 actual 的已发生时间链。可以记录意图、准备或犹豫本身已经发生，但要与未实施行为使用不同条目；无需为了每段相邻就补一条故事 before。
- name、alias、nickname 的值只放实际称形；“小名”“自称”“未具名”等说明写在 note 或条目标签中，不能混进名称检索字符串。
- 使用能保存实质信息的最小结构。普通属性直接接人物／物品；事件须先满足上面的准入条件。普通一次发言默认不建 utterance；实质内容用事实保存，话语本身确有独立引用用途时才建。仅在命题还被其他人相信、否认或后续验证时独立建 proposition。无需把同一发言再复制为三套同义节点。
- 普通动作原话已在事实证据中保存，不必另造同义 text_feature。确有措辞对比、重复、感官或叙述现象时再建，并连接对象；任何新节点须有可辨识的用途。这是减少重复编码，不是省略实质信息。
- 叙述明确某人想、怕、希望、误认时，保存认知内容与主体；“有人说了 P”可以是实际言语事件，但 P 本身仍是角色说法。未来、条件和否定必须落在对应事实，不能只藏在 note。

## 提交前与完成前

- 看原文反查实质遗漏，同时检查多建：有没有遗漏身份／关系、否定、计划、阶段变化、后果、信息差？新建的每个事件／言语／命题有什么不能由现有事实或原文承担的独立用途？不得为追求条目少而遗漏实质关系，也不得为覆盖声明而把所有动作都建成条目。
- 同时出现两个实体不能自动推导其关系；有关系也不要丢掉条件、说话者、否定或计划状态。
- 每批提交 complete=false，保存回执；后续复用已生成 ID。接手中断任务时先检查 prior_submissions，不能只凭 previously_declared_coverage 判断旧结果已经正确。
- 读完正文并完成逐段漏项核查后才 complete=true； unresolved 仍须保留。complete 是完成声明，不是人工验收。
- context_only 可以包含完整本章、相邻章及定向查找的远章。主事实仍有领取正文锚点；辅助依据放 context_support，coverage 只列正文。后文可确认前文关系，无需未来信息屏障；合理猜测仍不等于原文支持。
- 已否决事实不能作为事实依据。seed_unverified、pending、observed_label_candidate 都是候选；已否决实体、名称及提及退出默认候选和检索，历史仍保留。不确定时宁可新建候选并留线索，不把错误复用传播全书。

## 后续模型能做什么

先从这层检索人物／事件／场景／时间与语言观察，再回原文核对，可重建行为轨迹、关系转折、信息差、承诺与后果、重复意象候选。高级模型对主题、反讽、象征、伏笔与叙述可靠性提出解释时，必须返回依据与反例范围。Luna 负责充分保存证据，不能保证它从未遗漏文学上重要但表面普通的细节；抽样复核与定向补扫仍然必要。
